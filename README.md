# MirrorCity

MirrorCity is a district-scale digital twin prototype for city and disaster-management teams. It combines LiDAR and imagery into a navigable 3D planning workspace, then layers infrastructure, assets, and scenario simulations over the model.

The prototype includes a movable city view, LiDAR/image import flow, utility layer controls, asset inspection and placement, and sewer, flood, and evacuation scenario controls.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```
